Transformer Core Dataflow (Arms 1 & 8)

Full pairwise self-attention with ALiBi relative position biases across all keystrokes in the sentence.

flowchart TD IN["Keystroke Embeddings: x ∈ ℝ^(B × T × 512)"] --> LN1["LayerNorm(x)"] LN1 --> QKV["Q, K, V Linear Projections (2 Attention Heads)"] QKV --> ALIBI["Compute ALiBi Relative Slopes Bias:
B_ij = -m · |i - j|"] ALIBI --> SOFTMAX["Scaled Dot-Product Attention:
A = Softmax( (Q Kᵀ / √d_k) + B )"] SOFTMAX --> ATTN_OUT["Attn_Out = A · V"] ATTN_OUT --> PROJ["Output Linear Projection"] IN --> RES1["+ (Residual Add)"] PROJ --> RES1 RES1 --> LN2["LayerNorm"] LN2 --> MLP["Feedforward Network (MLP):
Linear(512, 2048) ➔ GELU ➔ Linear(2048, 512)"] RES1 --> RES2["+ (Residual Add)"] MLP --> RES2 RES2 --> TO_NEXT["Output to Next Block / Final Classifier"]

BiMamba-2 Pre-Norm Block (Arms 2, 3, 4, 5)

Forward and time-reversed Backward SSD mixers run in parallel and are summed to ensure fair bidirectional context.

flowchart TD X["Input x ∈ ℝ^(B × T × 512)"] --> NORM["RMSNorm(x)"] subgraph FWD ["Forward Mamba-2 SSD Mixer"] NORM --> INP_F["in_proj ➔ split: [z, xbc, dt_raw]"] INP_F --> CONV_F["1D Conv (kernel 4) + SiLU"] CONV_F --> SPLIT_F["Split: x_s (16×64), B (1×64), C (1×64)"] INP_F --> DT_F["Δt = Softplus(dt_raw + dt_bias)"] SPLIT_F & DT_F --> SSD_F["Quadratic SSD Dual Form:
y_fwd = ( (C · Bᵀ) ⊙ exp(cumsum(Δt · A)) · Δt ) x_s + D · x_s"] SSD_F --> GNORM_F["RMSNorm(y_fwd, gate=SiLU(z))"] GNORM_F --> OUT_F["out_proj(y_fwd)"] end subgraph BWD ["Backward Mamba-2 SSD Mixer"] NORM --> FLIP_IN["torch.flip(time_dim)"] FLIP_IN --> INP_B["in_proj ➔ Conv1D ➔ SSD Recurrence"] INP_B --> SSD_B["Quadratic SSD Dual Form (Reversed Order)"] SSD_B --> GNORM_B["RMSNorm(gate=SiLU(z)) ➔ out_proj"] GNORM_B --> FLIP_OUT["torch.flip(time_dim) ➔ y_bwd"] end OUT_F --> SUM["Sum: y_fwd + y_bwd"] FLIP_OUT --> SUM SUM --> DROP["Dropout(0.1)"] X --> RES["+ (Residual Add)"] DROP --> RES RES --> BLK_OUT["Output Block Embedding (B, T, 512)"]

BiMamba-3 Architecture Upgrades (Arms 6 & 7)

Adds BCNorm with learnable biases and complex-valued state tracking via data-dependent RoPE rotation.

flowchart TD X["Input x ∈ ℝ^(B × T × 512)"] --> INP["in_proj ➔ [z, xbc, dt_raw, θ] (Extra nheads outputs)"] INP --> CONV["1D Depthwise Conv (kernel 4) + SiLU"] CONV --> SPLIT["Split: x_s, Bmat, Cmat"] subgraph UPGRADE1 ["Upgrade 1: BCNorm + Learnable Biases"] SPLIT --> BCNORM["B = RMSNorm(Bmat) + b_bias
C = RMSNorm(Cmat) + c_bias
(Prevents unbounded norm growth)"] end subgraph UPGRADE2 ["Upgrade 2: Complex State via Data-Dependent RoPE"] INP --> PHASE["Per-head rotation rate θ_t ∈ ℝ^H
Cumulative angle: φ_t = cumsum(θ_t, dim=1)"] BCNORM & PHASE --> ROPE["Rotate State Dimensions:
B_rot = RoPE(B, -φ)
C_rot = RoPE(C, +φ)"] end ROPE --> SSD["SSD Dual Form Kernel:
(C_rot · B_rotᵀ) ≡ R(φ_t - φ_s) · (C_t · B_sᵀ)
y = ( (C_rot · B_rotᵀ) ⊙ L · Δt ) x_s + D · x_s"] SSD --> GNORM["Gated RMSNorm(y, gate=SiLU(z))"] GNORM --> OUT_P["out_proj(y)"]
